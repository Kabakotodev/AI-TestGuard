# Données

Le dataset **Credit Card Fraud Detection** est disponible sur Kaggle :
https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

## Instructions

1. Télécharger `creditcard.csv` (~150 Mo).
2. Le placer dans ce dossier : `data/creditcard.csv`.
3. **Ne pas le committer** (fichier volumineux, exclu par `.gitignore`).

## Alternative

Si le fichier est absent, les tests utilisent un dataset **synthétique**
généré via les fixtures pytest (voir `tests/conftest.py`).
